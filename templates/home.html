Frequently Asked Questions

What is the primary purpose of InvoSmart?
InvoSmart is an intelligent system designed to automate invoice data capture and validation for firms dealing with numerous suppliers and invoice formats.
How does the system handle uncertain data?
It provides automated confidence scoring with color-coded indicators (green, yellow, red) to help users identify and correct uncertain fields, ensuring high data quality.
Who are the main users of the platform?
The system supports Accounting Staff for invoice uploads and review, Branch Managers for monitoring and reports, and System Administrators for user and system management.
What file formats are supported?
The system accepts PDF, JPG, and PNG file formats for invoice uploads.
